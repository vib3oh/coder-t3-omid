# Omid’s T3 roadmap fork

A project roadmap inside T3’s existing web and desktop shell. Ideas stay on the
server that owns the project, so the board works across browsers and remote
connections without a GitHub repository or a separate cloud account.

starting upstream commit and the extension’s integration points. This is a
source fork; the installed T3 and HyperCoder applications are unchanged.
